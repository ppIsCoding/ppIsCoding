### 🏆 项目经历

#### [ZeroCraft - AI 零代码应用生成平台](https://github.com/ppIsCoding/ZeroCraft) | 核心开发

> AI Agent 自动完成素材搜集 → 代码生成 → 质检 → 构建 → 一键部署，多级缓存 + 分布式 + 异步重试保障稳定性

- 🔁 基于 **LangGraph4j** 实现多节点自动化工作流，把不确定的生成流程标准化
- 🛡️ **输入/输出护栏**：拦截敏感词与 Prompt 注入攻击，输出质量校验失败自动重试
- 📉 **成本优化**：按任务复杂度智能路由模型（生成用推理模型、分类用低成本模型）
- 📊 **可观测性**：ARMS 告警 + Prometheus / Grafana 自定义指标（Token 用量监控）
  `Spring Boot 3` `LangChain4j` `LangGraph4j` `Redis` `Prometheus`

#### [P-Prism - 超级智能体](https://github.com/ppIsCoding/p-prism) | 独立开发 · [在线体验](https://fronted-ivory.vercel.app/)

> 基于 Spring Boot 3 + Spring AI 的情感指导智能体，ReAct 模式自主调用工具完成复杂任务

- 🧠 参考OpenManus 设计**分层 Agent 架构**（BaseAgent / ReActAgent / ToolCallAgent），自主规划、任务分解、循环执行
- 🔧 基于 Spring AI 注解实现联网搜索、网页抓取、文件操作、PDF 生成等**多工具调用**
- 📚 **RAG 查询增强**：多查询扩展 + 查询重写 + 上下文增强，显著提升检索召回率
- 🌐 支持多轮对话与记忆持久化，已部署线上体验
  `Spring AI` `RAG` `PGVector` `Tool Calling` `MCP`

#### [AI 编程小助手](https://github.com/ppIsCoding/ai-code-helper) | 独立开发

> 基于 Spring Boot + LangChain4j 的 AI 编程学习助手：学习路线规划、项目指导、面试辅导

- 🤖 集成通义千问大模型，支持 MCP 协议与工具调用、SSE 流式响应
- 🖥️ 前后端分离：Spring Boot 3 + Vue 3 + Vite
  `Java 21` `Spring Boot` `LangChain4j` `SSE` `Vue 3`

#### [轻食智星 - AI 健康膳食助手](https://github.com/ppIsCoding/ai-recipe) | 独立开发

> 基于《中国居民膳食指南 2022》的健康菜谱推荐微信小程序

- 📷 百度 AI 拍照识别食材，AI 智能推荐菜谱，支持少盐 / 高蛋白等健康标签筛选
- 🏗️ FastAPI + LangGraph 多智能体协作架构
  `微信小程序` `FastAPI` `LangGraph` `MySQL` `百度AI`
